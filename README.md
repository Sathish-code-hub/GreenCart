🛒 GreenCart – Full Stack E-commerce Application

GreenCart is a full stack e-commerce web application built using the MERN stack. The goal of this project is to simulate a real-world online shopping experience, including product browsing, cart management, and secure payments.

🚀 Features
User authentication (signup & login)
Browse and search products
Add to cart and manage items
Secure checkout with Stripe integration
Order placement and tracking
Admin dashboard for product and order management
Responsive design for mobile and desktop

🛠️ Tech Stack:
Frontend:
React.js
Tailwind CSS
Axios

Backend:
Node.js
Express.js

Database:
MongoDB (Mongoose)

Other Tools:
Stripe (Payment Gateway)
JWT (Authentication)
Cloudinary (Image Upload)

🔄 Application Flow:
Users can register and log in securely.
Browse products and add items to the cart.
Proceed to checkout and complete payment via Stripe.
Stripe webhook confirms payment and updates order status.
Admin can manage products and view orders.

🔐 Authentication:
Authentication is handled using JWT.
Users receive a token after login, which is used to access protected routes.

💳 Payment Integration:
Stripe is used for handling payments.
Webhooks are implemented to ensure secure and reliable payment confirmation before updating order data.

📦 Deployment
Frontend: Vercel
Backend: vercel
Database: MongoDB Atlas
